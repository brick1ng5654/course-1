# Лабораторные и курсовые работы на C (strict c90) (01.09.23-01.06.24)

Особенности:
+ Использование одного выхода из программы (exit, break (в условных операторах) запрещены, один return)
+ Весь код находится в одном файле
+ Декларация переменных в начале блока
+ Наличие отчета и блок-схемы

Темы лабораторных работ:
1. Циклические вычисления на языке Cи
2. Обработка одномерных массивов
3. Обработка двумерных массивов
4. Применение функций
5. Обработка строк
6. Структуры. Массивы структур
7. Указатели на структуры и функции
8. Линейные односвязные списки
9. Линейные двусвязные списки
10. Кольцевые списки
11. Битовые поля в структурах

Тема курсовых работ:
1. Обработка текстовой информации
2. Разработка электронной картотеки
